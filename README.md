# RAG Chatbot for London Tech Week 2026

A Retrieval-Augmented Generation chatbot that answers questions about London Tech Week 2026 — speakers, agenda, sessions, and practical event information.

Built as the final project for the Codecademy Agentic AI Applications bootcamp (AGAI-03).

## Status

🚧 In development — submission deadline 29 May 2026.

## Stack

- Python 3.10+
- Anthropic Claude API
- LangChain
- Chroma (vector database)
- Streamlit (UI)
- BeautifulSoup + Requests (scraping)
